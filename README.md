# CivixLauncher 🚀

**CivixLauncher** is the persistent background sentinel of the CivixShield ecosystem. Built as a native Android utility app, it provides 24/7 real-time monitoring of notifications, clipboard activity, and phone calls to intercept scam threats before they reach the user.

## 🛡️ Key Features

### 1. Real-Time Notification Monitoring
Listens for incoming messages across all major communication and payment platforms:
- **Messaging:** WhatsApp, Telegram, Messenger, Google Messages, Samsung Messages.
- **FinTech/UPI:** Paytm, PhonePe, Google Pay, BHIM.
- **Email:** Gmail, Outlook.
- **Logic:** Extracts content and automatically scans for India-specific scam patterns (Digital Arrest, KYC scams, fake urgent payments).

### 2. Live Call Screening & Monitor
Provides a dual-layer defense for voice calls:
- **Call Screening:** Identifies and flags suspicious numbers based on real-time database lookups.
- **Active Call Analysis:** Monitors active call audio (via Accessibility/Live Captions) to generate real-time transcripts.
- **AI Forensic Report:** Sends call transcripts to **Llama 3 8B** (via OpenRouter) for immediate threat assessment and risk scoring.

### 3. Clipboard Sentinel
Continuously monitors the system clipboard. If a user copies a link or text that contains known scam signatures or malicious URLs, the Launcher intercepts it and notifies the main CivixShield app.

### 4. Deep Link Integration
Acting as a bridge, the Launcher package-encodes threat data and forwards it to the main **CivixShield React Native App** using a robust deep link pipeline (`civix://ingest`).

### 5. Threat Dashboard
A minimalist Jetpack Compose UI that provides:
- **Live Threat Counter:** Real-time visibility into total blocked threats.
- **System Status:** Health checks for Accessibility and Notification Listener permissions.
- **Recent Interceptions:** A glance at the most recent forensic reports generated by the AI.

## 🛠️ Technical Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Services:** 
  - `NotificationListenerService` (Message interception)
  - `AccessibilityService` (Call/Text monitoring)
  - `CallScreeningService` (Spam detection)
- **AI Integration:** OpenRouter API (Llama 3 8B)
- **Database:** Firebase Firestore (Cloud Vault)
- **Concurrency:** Kotlin Coroutines & Flow

## 🚀 Setup & Installation

1. Clone this repository alongside the main [CivixShieldApp](https://github.com/Harsh-Pathak3601/CivixShield-App).
2. Add your `google-services.json` to the `app/` directory.
3. Open in Android Studio and sync Gradle.
4. **Permissions Required:** 
   - Notification Access
   - Accessibility Service (for call monitoring)
   - Call Screening Privilege
   - Microphone/Record Audio (for speakerphone monitoring)
