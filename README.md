# CivixLauncher 🚀

**CivixLauncher** is the persistent background Protection Engine of the CivixShield ecosystem. Built as a native Android utility app, it provides 24/7 real-time monitoring of notifications and clipboard activity to intercept scam threats before they reach the user. 



## 🛡️ Key Features

### 1. Real-Time Notification Monitoring
Listens for incoming messages across all major communication and payment platforms:
- **Messaging:** WhatsApp, Telegram, Messenger, Google Messages, Samsung Messages.
- **FinTech/UPI:** Paytm, PhonePe, Google Pay, BHIM.
- **Email:** Gmail, Outlook.
- **Logic:** Extracts content and automatically scans for India-specific scam patterns (Digital Arrest, KYC scams, fake urgent payments).

### 2. Clipboard Monitoring 
Continuously monitors the system clipboard via OS intents. If a user natively copies a link or text block that contains known scam signatures or malicious URLs, the Launcher intercepts it and securely notifies the main CivixShield app for deep AI forensics.

### 3. Deep Link Integration
Acting as a bridge, the Launcher package-encodes threat data and forwards it directly to the main **CivixShield React Native App** using a robust deep link pipeline (`civix://ingest`).

### 4. Threat Dashboard
A minimalist Jetpack Compose UI that provides:
- **Live Threat Counter:** Real-time visibility into total messages screened.
- **System Status:** Health checks for the Notification Listener service integration.
- **Recent Interceptions:** A glance at the most recent forensic reports generated by the Cloud-AI.

## 🛠️ Technical Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Services:** 
  - `NotificationListenerService` (Message interception)
  - `ClipboardManager.OnPrimaryClipChangedListener` (Clipboard monitoring)
- **AI Integration:** OpenRouter API (Llama 3 8B edge-fallback)
- **Database:** Firebase Firestore (Cloud Vault)
- **Concurrency:** Kotlin Coroutines & Flow (`Dispatchers.IO`) inside dormant background layers.

## 🚀 Setup & Installation

1. Clone this repository alongside the main [CivixShieldApp](https://github.com/Harsh-Pathak3601/CivixShield-App).
2. Add your local environment constraints (e.g., `local.properties`).
3. Open in Android Studio and sync Gradle.
4. **Permissions Required:** 
   - **Notification Access:** Under Special App Access in your Android System Settings.
